# Tapeless — вибір фаху без «касети»

Окремий статичний сайт для GitHub Pages у стилі Poklych («М'яка Тиша»): людина вводить, що її цікавить і що вона
вміє, обирає умови (баланс життя й роботи, навчання, ризик, локація…) — а сайт збирає готовий **промпт** для
Claude / ChatGPT / Gemini / Perplexity, щоб вибрати діяльність чи професію, розібрати стереотипи, складнощі,
конкуренцію, зв'язок із блогерством, захищеність від ШІ й знайти людей, які вже побудували в цьому кар'єру.

Статус: **плани й промпт готові (2026-10-19), код ще не написано.** Це інкубатор: коли сайт піде в роботу,
вміст папки копіюється в окремий репозиторій `tapeless` (див. «Запуск»).

## Назва

Книга Азімова «Профессія» (*Profession*, 1957; укр. «Фах»): у світі, де на 18-річчя професію «записують» на
людину касетою (education tapes), герой Джордж Платен виявляється тим, кому касета не підходить, — і саме такі люди
вигадують нове. Сайт робить протилежне: **не призначає фах, а допомагає обрати його самому.**

Обрано **Tapeless** («без касети»): коротко, пишеться латиницею однаково українською й англійською, одразу
натякає на сюжет, а слоган читається без знання книги: *«Choose a profession. Don't get assigned one.»*
Українською: *«Обери фах сам — без касети»*. Візуальна тема — жовто-чорна стрічка (є в Poklych як `--tape-yellow`).

Запасні варіанти, якщо Tapeless зайнято або не сподобається: **Platen** (прізвище героя; для тих, хто знає
книгу), **Unassigned** («непризначений»), **Higher House** («Дім вищої освіти» — місце, де вчать думати),
**Registration Day** (день, коли призначали фах). Перед фіксацією перевірити вільність репозиторію й домену.

## Адреса

**https://doutivity.github.io/tapeless/** — проєктний сайт GitHub Pages (акаунт `doutivity`, репозиторій `tapeless`). Сайт
живе в підкаталозі `/tapeless/`, тому всі шляхи відносні або від `basePath`, а канонічна адреса, `og:url`,
`og:image`, `sitemap.xml` і `manifest` беруть `siteUrl` з `site.config.json`:
`{ "siteUrl": "https://doutivity.github.io/tapeless", "basePath": "/tapeless/" }`.

## Запуск

1. Створити репозиторій `tapeless` (публічний), скопіювати туди `PROMPT.md`, `PLAN.md`, `llm-prompt-template.md`,
   `content-seed.md` і `design-source/` (у підпапку `design-source/`, не в корінь).
2. Відкрити сесію Claude Code в цьому репозиторії й віддати вміст `PROMPT.md`.
3. Після готового сайту: GitHub → Settings → Pages → Source: *GitHub Actions* (workflow входить у завдання).
4. За бажанням — власний домен (`CNAME`), тоді змінити `siteUrl` і `basePath` у `site.config.json` (адреси скрізь
   підтягуються звідти); старі посилання на `doutivity.github.io/tapeless` GitHub перенаправляє на домен.

## Принципи

- Лише HTML, CSS, vanilla JS — без каркасів, збірника й залежностей у браузері. Опційний скрипт збірки
  статичних сторінок — стандартна бібліотека Python, не в рантаймі.
- Відповіді форми не покидають пристрій, доки людина сама не натисне «Відкрити в …» чи «Копіювати». Єдиний виняток
  у мережі — **Google Analytics 4, і лише після явної згоди** (банер-попередження, вмикається й вимикається
  будь-коли); відповіді форми в аналітику не потрапляють ніколи.
- Чесно про межі: відповіді ШІ можуть помилятися, імена й цифри треба перевіряти — промпт це вимагає від ШІ.
- Стиль і тон — як Poklych: спокійно, на «Ви», без реклами й тиску.
